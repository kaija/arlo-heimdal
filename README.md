# Heimdal service page

A standalone, responsive landing page for Heimdal’s family scam-protection service.

Open `index.html` directly in a browser. The page packages the Arlo design-system stylesheet, tokens, and favicon under `vendor/arlo/` and `assets/` so it does not depend on a running app or a sibling checkout.

The product language and guardrails are derived from the Heimdal repository’s `intent.md`: explicit consent, guardian visibility levels, local-first screening, human judgement, and strictly read-only operation.

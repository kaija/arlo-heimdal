# Arlo service page

A standalone, responsive landing page for Arlo’s family scam-protection service.

Open `index.html` directly in a browser. The page packages the Arlo design-system stylesheet, tokens, and favicon under `vendor/arlo/` and `assets/` so it does not depend on a running app or a sibling checkout.

The product language and guardrails are derived from the project’s product brief: explicit consent, guardian visibility levels, local-first screening, human judgement, and strictly read-only operation.

The public legal pages are [Arlo Privacy Policy](docs/privacy-policy.html) and [Arlo Terms of Use](docs/terms-of-use.html). The GitHub Pages workflow publishes the landing page and these documents from `main`.
